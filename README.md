# Restaurant-Sales-Analysis
Restaurant sales analysis and interactive dashboard using Tableau  Desktop.
Restaurant Sales Analysis Dashboard

Project Overview

This project analyzes restaurant sales data using Tableau Desktop to understand sales performance, customer ordering patterns, payment preferences, and branch-wise revenue.

Tools Used

Tableau Desktop
Data Visualization
Sales Data Analysis

Key Performance Indicators

Total Sales: AED 2.35 Million
Total Orders: 3,600
Average Order Value: AED 652.98
Total Items Sold: 28.5K
Top Performing Branch: Jumeirah

Key Insights

Dine-In recorded the highest sales among channels at approximately AED 843K.
Card payments recorded the highest sales among payment methods at approximately AED 661K.
Jumeirah was the top-performing branch at approximately AED 810K.
Mains was the leading category at approximately AED 1.545M.

Dashboard Features

Sales KPI cards
Sales by channel and payment type
Sales trend analysis
Top 10 menu items by sales

Category-wise sales

Branch-wise sales comparison

Interactive filters
